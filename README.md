## Password Generator

This project is a simple and stylish password generator web application with interactive features.

## See Demo
* ****:https://sarthak03dot.github.io/Password-Generator/

### Features

* **Password Generation:** Generates random passwords of varying lengths and complexities.
* **Copy Functionality:** Easily copy the generated password to your clipboard with a single click.


### Technologies Used

* HTML: Structures the web page content.
* CSS: Provides styling and animations for visual appeal.
* JavaScript: Implements the password generation logic and copy functionality.

### How to Use

1. **Clone or Download the Repository:** Obtain the project files using Git or by downloading them directly.
2. **Open in a Web Browser:** Open the `index.html` file in any modern web browser.
3. **Generate and Copy Passwords:** Click the "Generate" button to create a random password. Then, click "Copy" to copy it to your clipboard.
4. **Enjoy the Animation:** Observe the continuous scrolling text animation  at the top of the screen.
